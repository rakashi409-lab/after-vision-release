# After Vision · 视界之后

把平面图像，变成可以转动的光 —— 一个 Photoshop 插件。

它把一个平面图层抠出背景、读出深度，生成能 **360° 旋转、还能重新打光** 的立体图层，结果直接写回原图层；立体信息随 PSD 一起保存。

> 落地页：**https://rakashi409-lab.github.io/after-vision-release/**

## 下载

前往 [**Releases**](https://github.com/rakashi409-lab/after-vision-release/releases/latest) 下载最新 Windows 安装程序，运行后按向导把面板装进你的 Photoshop。

> 首次下载或安装时若出现安全提示（「不常下载」「Windows 已保护你的电脑」），这是系统对新发布程序的信誉提醒，并非检测到病毒。放行方法与 SHA-256 文件校验见[落地页常见问题](https://rakashi409-lab.github.io/after-vision-release/#safe)，校验值也写在每个发行版的说明里。

## 本机 / 云端

- **立体功能全程在本机运行**：抠图、深度、建模、重新打光，安装后开箱即用，断网也能用，图像不离开你的电脑。
- **精绘 / 生图为可选的云端增强**：会调用第三方付费服务，需要你在面板里填入自己的账户信息后启用；安装包不含任何密钥或账号。不配置也不影响立体功能的完整使用。
